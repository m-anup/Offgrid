# OFFGRID Studio

> Creative Marketing & Design Agency — We make brands impossible to ignore.

An editorial, high-performance agency portfolio website crafted with pure **HTML5**, **CSS3**, and **Vanilla JavaScript**. Features interactive kinetic canvas visuals, bespoke micro-interactions, custom magnetic cursor mechanics, and a sleek dark aesthetic.

---

##  Features

- **Interactive Kinetic Canvas:** Particle & wave background rendered with HTML5 Canvas.
- **Custom Magnetic Cursor:** Trailing physics with contextual states (`VIEW ↗`, button hover, touch detection).
- **Project Showcase & Modal:** Detailed case studies with interactive image previews and tags.
- **Services Accordion:** Interactive breakdown of agency capabilities and offerings.
- **Scroll Progress & Reveal Animations:** Top scroll progress indicator with smooth intersection observer reveals.
- **Contact Form & Toast System:** Interactive consultation form and one-click email copying toast notification.
- **Live World Clocks:** Real-time studio timezone clocks.
- **Pure Vanilla Stack:** Zero dependencies, zero build steps, lightweight and blazing fast.

##  Getting Started

No build tools or package managers required. Simply serve the files locally using any static web server:

### Option 1: Python
```bash
# Python 3
python -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

### Option 2: Node.js (npx)
```bash
npx serve .
```

### Option 3: VS Code Live Server
Right-click `index.html` and select **"Open with Live Server"**.
